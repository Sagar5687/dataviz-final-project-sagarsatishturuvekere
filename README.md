# 🎮 Steam Games Data Visualization Dashboard

An interactive data visualization dashboard developed using **Python, Streamlit, and Plotly** as part of the **Data Visualization** course in the **M.Sc. Data Science** program. The project analyzes Steam game data through a series of interactive visualizations, enabling users to explore trends in game releases, genres, pricing, developers, publishers, and user ratings.

# 📌 Project Overview

The Steam platform contains thousands of games with diverse genres, developers, publishers, pricing models, and user reviews. This project presents an interactive dashboard that transforms raw Steam data into meaningful visual insights using modern data visualization techniques.

The dashboard consists of **12 analytical visualizations**, each designed to answer a specific business or analytical question using interactive Plotly charts within a Streamlit application.

---

- Interactive Streamlit Dashboard
- Custom CSS-based Interface

- Data Filtering and Exploration
- Responsive Dashboard Design
- Analytical Data Storytelling

---

# 📊 Analytical Questions

The dashboard explores the following questions:

1. Which game genres dominate the Steam platform?
2. How has the number of game releases changed over time?
3. Which genres receive the highest user ratings?
4. What is the relationship between game price and user ratings?
5. Which developers have released the most games?
6. Which publishers dominate the Steam marketplace?
7. How are game prices distributed across the platform?
8. Which genres provide the best value for players?
9. Which developers consistently produce highly-rated games?
10. How have game ratings changed across release years?
11. Which developer and genre combinations occur most frequently?
12. Which game categories perform best across multiple performance metrics?

# 🚀 Running the Project

Clone the repository:

```bash
git clone https://github.com/Sagar5687/dataviz-final-project-sagarsatishturuvekere.git
```

Navigate to the project directory:

```bash
cd dataviz-final-project-sagarsatishturuvekere
```

Install the required dependencies:

```bash
pip install -r Dashboard/requirements.txt
```

Launch the Streamlit dashboard:

```bash
streamlit run Dashboard/app.py
```
